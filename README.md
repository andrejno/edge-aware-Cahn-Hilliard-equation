# CHPM

Research website for *Analysis and numerical evaluation of an edge-aware Cahn–Hilliard equation for binary image inpainting*.

## Website

Open `index.html` to view the website. The comparison viewer contains 24 synthetic cases and 56 retinal crop–mask cases, with six methods for each case. Tables, coefficient plots, error overlays and downloadable phase fields are included.

## Numerical notebook

[`notebooks/chpm_results.ipynb`](notebooks/chpm_results.ipynb) contains executed cells and embedded outputs. The [HTML notebook](notebooks/chpm_results.html) opens directly in a browser.

The notebook aggregates the full-precision numerical records, recomputes paired comparisons, displays all 480 reconstructions, and reruns the manufactured-solution, temporal-convergence, operator-agreement and mass-balance tests.

With Python 3.12, run from the repository root:

```bash
python -m pip install -r requirements.txt
python scripts/build_notebook.py
```

This executes the notebook and writes both notebook formats. Jupyter can also run the `.ipynb` file directly.

## Reconstructions

The 80 input cases and 480 phase fields are included. The fields are stored as compressed NumPy arrays under `data/fields`; the score records retain full precision under `data/records`.

To regenerate the reconstructions from the supplied inputs:

```bash
python scripts/reconstruct.py --dataset all --workers 4 --force
python scripts/build_assets.py
python scripts/build_notebook.py
```

To verify the existing fields against the recorded masked Dice and RMSE values:

```bash
python scripts/reconstruct.py --dataset all --workers 4
```

## Files

| Path | Contents |
| --- | --- |
| `index.html`, `assets/` | Website, interactive figures and CSV tables |

| `scripts/` | Reconstruction and figure generation |

| `data/refinement/` | Saved refinement fields |
| `data/records/` | Scores, parameter selection and numerical diagnostics |

## Data

Retinal images and annotations are from [STARE](https://cecas.clemson.edu/~ahoover/stare/probing/): A. Hoover, V. Kouznetsova and M. Goldbaum, *Locating Blood Vessels in Retinal Images by Piecewise Threshold Probing of a Matched Filter Response*, IEEE Transactions on Medical Imaging 19(3), 203–210 (2000), [doi:10.1109/42.845178](https://doi.org/10.1109/42.845178).

AH is the primary reference annotation, VK is the second observer. Each of the 14 test source images contributes two crops and two scratch widths. Synthetic cases are generated by `src/benchmarks.py`.
